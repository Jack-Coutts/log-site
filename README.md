# streak-site

The website for [streak](https://jack-coutts.github.io/streak-site/), the private exercise log for iPhone.

- `index.html` is the home page.
- `support.html` is the user guide. It's the App Store support URL.
- `privacy.html` is the privacy policy. It's the App Store privacy URL.
- `style.css` is shared by all three pages. It's boast-site's, with a few additions at the end.
- `img/` holds the app screenshots, as 660 × 1434 WebP.

Plain HTML and CSS, with no build step. GitHub Pages serves the `main` branch.
